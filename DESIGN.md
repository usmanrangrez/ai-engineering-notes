# Design direction

User brief: minimal Swiss documentation; JetBrains Mono headings, IBM Plex Sans body; one blue accent; light/dark themes; sidebar TOC; previous/next and code copy; no gradients or emoji icons.

UI UX Pro Max query: technical documentation minimal swiss. Verified match: FAQ/Documentation Landing + Minimalism & Swiss Style, suitable for documentation. Apply navigation, whitespace, contrast and search guidance. Discard support-ticket conversion CTAs and marketing hero recommendations. User-specified typography overrides the query's Inter suggestion. Stack is static HTML/CSS/JavaScript generated by Python; no frontend framework is required.

Light tokens: white background #ffffff, ink #17202b, muted #525c69, blue #2458cf, surface #f5f6f8. Dark tokens: background #11151b, ink #e9edf2, muted #a8b2c0, blue #94b7ff, surface #191f28. Theme is stored locally. Semantic structure and text labels carry status, not color alone.

Layout: a compact sticky header, a chapter navigation rail, a reading column, and an on-page TOC at wide widths. The mobile chapter menu is a disclosure, not an inaccessible hover-only menu. Code and reference tables scroll within their own containers. No decorative motion or raster assets are needed.
